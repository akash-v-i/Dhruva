# Dhruva

Polar knowledge and outreach portal for expeditions, stations, reports, publications, datasets and media.

## Development

You need Node.js and a package manager (npm, bun, or similar).

```sh
git clone <this-repository-url>
cd dhruva
npm i
npm run dev
```

## Built with

- TanStack Start
- TypeScript
- React
- Tailwind CSS
